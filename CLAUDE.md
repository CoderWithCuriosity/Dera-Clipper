# AI Clipper: project progress

Last updated: 2026-11-26

## What this is

AI Clipper turns long videos into short clips with captions. The user picks a clip length, number of clips, theme, orientation (landscape, vertical 9:16, square), and captions. A language model picks the moments. FFmpeg does all cutting, framing, captions, and audio. Specification: the pasted "AI Clipper: Project Document Set" (12 documents).

## Decisions

- **Transcription:** local Whisper only. AWS Transcribe is not used. It needs a subscription on the account, and the user chose not to use it.
- **Orientation:** treated as output framing (landscape, vertical, square). Added in Phase 1 rather than Phase 4.
- **Links:** direct video file URLs always work. YouTube links use yt-dlp, but only when `CLIPPER_ALLOW_PLATFORM_LINKS=true` (off by default). The user chose to accept YouTube's terms risk. The New project page shows a warning when it's on.
- **Effects:** placeholder tones and colour clips are generated by `scripts/make_placeholder_effects.py`. Real licensed effects must be added by the user.
- **AWS credentials on the server:** the EC2 instance uses an IAM role (`instanceRole`). No access keys are stored on the server or in the app.
- **Model:** the app has no AI key yet. Clip selection falls back to a heuristic (speech density) until a provider such as Groq, Gemini, or Ollama is added on the Setup page.

## Lessons from testing

- A fresh install had no effects until the library was scanned. The app now scans at startup.
- The first account was not becoming admin because a local profile row was counted. Fixed.
- Access tokens issued in the same second were identical. Each token now has a unique ID.
- Presigned S3 URLs need SigV4 signing. Set in the S3 adapter.
- With faster-whisper 1.2, PyAV 19 fails (`metadata_errors` error). PyAV 16.1 works. Pinned as `av>=11,<17`.
- The first Whisper run downloads the model, which takes minutes. Allow for that when timing.
